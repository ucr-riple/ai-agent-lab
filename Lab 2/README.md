## Quick start

```bash
cd /mnt/AI_Agent_Lab2
bash setup.sh
source .venv/bin/activate
```

Set API key in `.env`:

```text
GEMINI_API_KEY=YOUR_ACTUAL_API_KEY_HERE
```

Run tasks:

```bash
python lab2_task1.py
python lab2_task2.py --mode both
```
