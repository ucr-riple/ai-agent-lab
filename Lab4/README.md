# Lab 4: System Architecture & Interface Design

This folder contains a two-task Lab 4 workflow:
- Task 1: Agent smoke test
- Task 2: System architecture design for student projects

## Goal
Practice modular system design by defining clear boundaries and contracts across:
- `interface` (interaction/presentation)
- `engine` (logic/orchestration)
- `storage` (persistence/data integrity)

## How To Use This Lab
1. Complete `task1/README.md` first.
2. Complete `task2/README.md` second.
3. Submit Task 2 using `task2/WORKSHEET.md`.

## Deliverables
- [ ] Task 1 completed with passing Bubble Sort tests (i.e., the generated Python scripts and execution screenshots)
- [ ] Task 2 worksheet completed (`task2/WORKSHEET.md`)
- [ ] A text file to show that the student can explain why boundaries reduce coupling and improve maintainability
